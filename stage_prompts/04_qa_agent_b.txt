## Method — Screenshot-Driven Visual Audit

### Step 1 — Launch both apps
```bash
# macOS app
open -a /Applications/KanbanClaude.app
sleep 3

# Web app reachable?
curl -s -o /dev/null -w "%{http_code}" https://kanban.npalakurla.com/
```

### Step 2 — For every screen in FEATURE_PARITY_REGISTRY.md
Navigate to the screen in both apps. Screenshot both.

```bash
screencapture -x /tmp/macos_<screen>.png
# Use SPA nav (Rule 18 — never reload):
osascript -e 'tell application "Google Chrome"
  set windowID to id of active tab of front window
  execute active tab of front window javascript "if(typeof window.nav==='\''function'\''){window.nav('\''<screen>'\'');}else{location.hash='\''#<screen>'\'';}"
end tell'
sleep 2
screencapture -l $(GetWindowID "Google Chrome" "*") /tmp/web_<screen>.png 2>/dev/null || \
  screencapture -x /tmp/web_<screen>.png
```

Read both screenshots with the Read tool.
For each visible element in the web screenshot: is it present in macOS? Same layout? Same data?

### Step 3 — For each screen, also check
- Empty state (no data)
- Error state (trigger failed request)
- Selected / active states
- Scroll behavior to bottom
- Hover behaviors (Rule 12 — grep web for mouseover/hover/tooltip on this screen)
